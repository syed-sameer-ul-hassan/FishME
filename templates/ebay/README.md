## How It Works


### Features

- **Realistic Design**: Mimics the official eBay login interface with accurate styling, colors, and layout
- **Credential Capture**: Captures username and password entered by users
- **Data Collection**: Records IP address, user agent, and timestamp of capture attempts
- **Responsive Layout**: Works seamlessly on desktop and mobile devices
- **Form Validation**: Includes client-side validation for realistic user experience
- **Redirect Behavior**: After credential submission, redirects users to a controlled security  alert page
- **E-commerce Theme**: Incorporates eBay's branding and e-commerce focused design

### Technical Details

- **Entry Point**: `index.php` - Main login page
- **Form Handler**: `login.php` - Processes credential submission
- **Data Storage**: Captured data saved to JSON format in the capture directory
- **Styling**: Custom CSS matching eBay's design language
- **Assets**: Includes eBay logo and brand elements for authenticity

## How It Works

This template simulates a free Instagram followers generator website to capture user credentials.

### Features

- **Realistic Design**: Modern UI with Instagram's gradient colors and professional styling
- **Credential Capture**: Captures username, password, and selected follower count
- **Follower Selection**: Interactive options for 50, 100, 150, 200, 250, 500, 750, and 1000 followers
- **Data Collection**: Records IP address, user agent, timestamp, and selected follower count
- **Responsive Layout**: Works seamlessly on desktop and mobile devices
- **Form Validation**: Includes client-side validation for realistic user experience
- **Loading Animation**: Simulates processing delay for authenticity
- **Password Toggle**: Show/hide password functionality
- **Redirect Behavior**: After credential submission, redirects to official Instagram login page

### Technical Details

- **Entry Point**: `index.php` - Redirects to index.html
- **Main Page**: `index.html` - Followers generator interface
- **Form Handler**: `login.php` - Processes credential submission
- **JavaScript**: `script.js` - Enhanced interactivity and form handling
- **Styling**: `style.css` - Custom CSS with Instagram gradient theme
- **Data Storage**: Captured data saved to JSON format in the capture directory

### Usage

1. Select this template when starting a FishMe session
2. Configure your desired port and tunneling options
3. Share the generated URL with target users
4. Monitor captured credentials through the FishMe viewer
